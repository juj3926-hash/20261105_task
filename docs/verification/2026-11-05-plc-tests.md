# PLC 시험 기록

**상태: 실제 PLC 시험 미실행. 아래 항목은 모두 미확인이다.**

가짜 클라이언트 단위 테스트(`tests/test_plc.py`)는 실제 PLC 시험 결과가 아니다.

## 실제 연결 설정

| 항목 | 값 |
|---|---|
| COM 번호 | 미확인 |
| 데이터 비트·패리티·정지 비트 | 미확인 |
| 통신 속도 | 9600 |
| PLC 국번 | 1 |
| timeout·retries | 2초, 0 |
| 감시 주기 | 1초 |
| 시작 값 | 미확인 |
| PyModbus | 3.16.1 |

## 시험 절차

두 프로그램에서 각각 진행한다. 다음 프로그램 전에 `quit`으로 종료한다.

1. **정상:** 감시 확인 → `write 100` → `write_result`와 `write_confirmed` 확인 → `write 200` 반복
2. **무응답:** 강사 확인 뒤 `unit 2` → `read_sent` 직후 `status` 입력 → 입력한 시각을 화면 녹화나 수기로 기록 → 프로그램의 `input_received` 시각과 `observation_error` 시각 비교 → `write 300`도 입력해 처리 확인
3. **복원:** `unit 1` → 새 `observation` 확인 → `write 400` → 재조회 확인
