# PLC 비동기와 동기 비교 기록

**상태: 실제 PLC 시험 전이라 작성하지 않았다. 아래 자리는 실제 로그로 채운다.**

이 비교는 단일 실행 흐름에서 동기 통신을 사용하는 조건에 대한 것이다. 동기 통신을 쓰는 모든 프로그램으로 일반화하지 않는다.

## 1. 응답 대기 중 어떤 차이가 있었는가?

| 항목 | 비동기판 | 동기판 |
|---|---|---|
| 읽기 요청 시각 (`read_sent`) | 미확인 | 미확인 |
| 입력을 시도한 시각 (수기·녹화) | 미확인 | 미확인 |
| 프로그램이 반응한 시각 (`input_received`) | 미확인 | 미확인 |
| 시간 초과 시각 (`observation_error`) | 미확인 | 미확인 |
| 대기 중 표시 (`waiting`) | 미확인 | 미확인 |

## 2. 동기판의 어느 처리가 다른 일을 기다리게 했는가?

통신 응답 대기와 사용자 입력 대기를 구분해 실제 로그로 쓴다. 미작성.

## 3. 동기로 충분한 상황과 비동기가 필요한 상황은 무엇인가?

이번 프로그램에서 대기 중 다른 처리가 필요하지 않은 경우와 필요한 경우를 들어 쓴다. 미작성.
