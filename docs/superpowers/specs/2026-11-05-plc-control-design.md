# PLC 감시·값 변경 설계

- 대상 파일: `plc/plc_project.py`(비동기), `plc/plc_project_sync.py`(동기)
- 요구사항: `plc/TASKS_2.md`
- 범위: 과제 1·2, 시험 3개, 비교 기록. 선택 실습은 포함하지 않는다.

## 1. 목표

실제 PLC의 D01000을 계속 확인하면서 사용자 요청으로 값을 바꾸는 프로그램을 비동기와 동기로 각각 만든다. 무응답 대기 중의 입력 반응과 기록을 근거로 이번 동기판 조건의 한계를 설명한다.

## 2. 자료에 정해진 사실

### 장치와 통신

- PLC 내장 Cnet 채널 2, RS485 Modbus RTU, 9600, PLC 국번 1
- 읽기는 FC03·주소 0·수량 1, 쓰기는 FC06·주소 0. 주소에 1000이나 40001을 넣지 않는다.
- 값은 10진수이고 0~65535 정수를 쓴다.
- 강사가 사용하지 않는다고 확인한 D01000 테스트 워드만 다룬다.
- Python 3.10 이상, PyModbus 3.16.1

### 규칙

- 같은 연결의 요청은 한 번에 하나씩 처리한다.
- 읽기에 실패한 값을 0이나 새 관측값으로 표시하지 않는다. 성공한 읽기가 없으면 미관측으로 표시한다.
- 비동기판은 응답 대기 중에도 입력과 로컬 표시를 처리한다. 응답 대기가 끝난 뒤에야 반응하면 수정한다.
- 동기판의 제어 흐름에 스레드·별도 프로세스·asyncio 동시 처리를 넣지 않는다.
- 두 프로그램의 통신 설정, 감시 주기, timeout, 재시도, 입력 방식, 시험 상황을 같게 맞춘다.
- 두 프로그램을 동시에 실행하지 않는다. QModMaster 연결을 해제한 뒤 실행한다.
- 국번 0은 쓰지 않는다.

## 3. 실행 전 확인할 사항

코드에 기본값을 두지 않고 실행 인자로 받는다. 값을 확인해 시험 기록에 남긴다.

| 항목 | 상태 |
|---|---|
| COM 번호 | COM3에 CP210x 어댑터가 보이지만 수업용 어댑터인지 미확인 |
| 데이터 비트, 패리티, 정지 비트 | 미확인 |
| D01000 미사용 | 강사 확인 필요 |
| 독립 실습선에 국번 2 장치 없음 | 강사 확인 필요 |
| Windows에서 `AsyncModbusSerialClient` 동작 | 실제 포트에서 확인 필요 |

실제 PLC에 쓰는 시험은 위 항목을 확인한 뒤에만 실행한다.

## 4. 구현 선택

자료가 정하지 않아 이 설계에서 결정한 내용이다.

| 항목 | 선택 | 이유 |
|---|---|---|
| 입력 방식 | 터미널 명령 | 입력과 반응 시점을 기록하기 쉽다 |
| 감시 주기 | 1초 | 무응답 대기와 구분하기 쉽다 |
| timeout, retries | 2초, 0 (모든 시험 공통) | 시험 조건을 하나로 맞춘다 |
| 연속 요청 | 접수 순서대로 하나씩 처리. 거절·병합 없음 | 가장 단순하고 기록이 명확하다 |
| 쓰기와 읽기 순서 | 대기 중인 쓰기를 다음 감시 읽기보다 먼저 보냄 | 사용자 요청을 먼저 처리한다 |
| 실패한 쓰기 | 기록만 하고 재전송하지 않음 | 과거 요청이 뜻밖의 시점에 실행되지 않게 한다 |
| 국번 변경 | 실행 중 `unit` 명령. 다음 요청부터 적용 | 재시작 없이 시험 둘·셋을 진행한다 |
| 대기 중 쓰기의 대상 | 처리되는 시점의 국번 | 요청마다 국번을 저장하지 않는다 |
| 키 입력 | `msvcrt`로 키 확인, 줄 단위 명령 조립 | 동기판도 스레드 없이 입력을 받는다 |
| 기록 위치 | 터미널과 `plc/logs/`의 JSONL | 과제 1·2와 같은 방식이다 |

## 5. 명령

| 명령 | 동작 |
|---|---|
| `write <값>` | 값 변경 요청. 0~65535 정수가 아니면 `input_rejected` |
| `unit <국번>` | 대상 국번 변경. 1~247이 아니면 `input_rejected` |
| `status` | 마지막 정상 값·시각, 현재 오류, 대상 국번, 대기 요청 수 표시 |
| `quit` | 프로그램 종료, COM 포트 해제 |

그 밖의 입력은 `input_rejected`로 기록한다. 프로그램 종료는 PLC 값 변경과 무관하다.

## 6. 기록

모든 사건에 `wall`(벽시계 시각), `elapsed`(실행 시작부터의 초), `type`을 남긴다.

| type | 추가 필드 | 시점 |
|---|---|---|
| `run_start`, `run_end` | 연결 설정 | 시작과 종료 |
| `input_received` | text | 프로그램이 명령 한 줄을 처리한 시점 |
| `input_rejected` | text, reason | 명령 거절 |
| `request_accepted` | value, pending | 쓰기 요청 접수 |
| `unit_changed` | unit | 국번 변경 |
| `write_sent` | value, unit | 쓰기 요청 직전 |
| `write_result` | value, unit, ok, error | 쓰기 응답 또는 실패 |
| `read_sent` | unit | 읽기 요청 직전 |
| `observation` | value, unit | 읽기 성공 |
| `observation_error` | unit, error | 읽기 실패 |
| `write_confirmed` | value | 쓰기 성공 뒤 읽은 값이 요청 값과 일치 |
| `waiting` | seconds | 비동기판의 응답 대기 표시 |

`write_confirmed`는 성공한 쓰기 값을 기억했다가 다음 `observation`에서 비교한다. 값이 다르면 `write_mismatch`(value, observed)를 남긴다. 어느 쪽이든 비교는 한 번만 한다.

## 7. 구조

| 파일 | 역할 |
|---|---|
| `plc/plc_common.py` | 인자 해석, 명령 해석, 상태 보관, 로그. 통신과 대기 없음 |
| `plc/plc_project.py` | 비동기 실행 |
| `plc/plc_project_sync.py` | 동기 실행 |

공통 파일은 입력 방식과 원칙이 같다는 것을 코드로 보장한다.

### 비동기판

- 통신 Task: 쓰기 대기열이 있으면 쓰기, 없고 주기가 되었으면 읽기를 처리한다. 이 Task 하나만 Modbus 요청을 보내 한 번에 하나를 보장한다.
- 입력 Task: 약 0.05초 간격으로 키를 확인하고 명령을 처리한다.
- 표시 Task: 응답 대기 중 약 0.5초마다 `waiting`을 남긴다.
- `quit`이나 Ctrl+C에서 Task를 취소하고 연결을 닫는다.

### 동기판

한 반복에서 키 입력 처리 → 쓰기 처리 → 주기가 되었으면 읽기 → 짧은 대기(0.05초)를 수행한다. 통신 함수가 반환한 뒤에 다음 처리를 진행한다. 응답 대기 중에는 입력과 표시가 처리되지 않으며, 이 지연은 수정 대상이 아니라 측정 대상이다.

## 8. 오류 처리

- pymodbus 예외와 오류 응답(`isError()`)을 `ok=false`로 기록하고 프로그램은 계속한다.
- 읽기 실패 시 마지막 정상 값·시각을 유지하고 현재 오류만 바꾼다. 읽기 성공 시 오류를 지운다.
- 시작 시 포트를 열지 못하면 원인을 안내하고 종료한다.
- 실행 중 연결이 끊어지면 다음 요청 전에 다시 연결을 시도한다. 이 재연결은 요청 재전송이 아니다.

## 9. 검증

### 단위 테스트

PLC 없이 `tests/test_plc.py`에서 가짜 Modbus 클라이언트로 확인한다.

- 명령 해석과 범위 거절
- 읽기 실패 시 값 유지, 미관측 표시, 복원 시 오류 해제
- 접수 순서 처리, 재전송 없음, 쓰기 우선
- 비동기판: 응답 지연 중 입력이 접수되고 `waiting`이 기록됨. 동시 요청이 없음
- 동기판: 응답 지연이 끝난 뒤에 입력이 처리됨

### 실제 PLC 시험

`plc/TASKS_2.md`의 세 시험을 두 프로그램에서 각각 실행한다. 사용자가 진행하며, 동기판의 입력 시도 시각은 프로그램이 알 수 없으므로 화면 녹화나 수기로 남긴다.

결과는 `docs/verification/`의 시험 기록 표와 비교 기록에 남긴다. 비교 기록은 `TASKS_2.md`의 세 질문에 답하고, 단일 실행 흐름 조건으로 범위를 한정한다.
